# Gallery

Skies StarCanopy has made, each unrolled flat as an equirectangular map. Every one
renders again exactly from the project file beside it:

```bash
./build/starcanopy render open.toml
```

Each project records the look version it was made with; a later StarCanopy either
renders the same sky or says why it cannot.
