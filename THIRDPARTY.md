# Third-party components

StarCanopy is GPLv3. Every component below is GPLv3-compatible. A component is
added to this list in the same change that makes the code depend on it.

**Status.** Everything below is in the tree, with its pinned version.

| Component | Use | Licence | Obligations |
|---|---|---|---|
| SDL3 (submodule `extern/SDL`, `release-3.4.16`) | Window, input, GL context | zlib | Notice in documentation appreciated, not required |
| Dear ImGui (submodule `extern/imgui`, `v1.92.9b`) | Interface | MIT | Keep the copyright notice |
| glad (generated by glad 2.0.8 into `extern/glad`) | OpenGL 3.3 core loader | Generated code `(WTFPL OR CC0-1.0) AND Apache-2.0`; `khrplatform.h` Khronos MIT-style | Keep the SPDX line and the `khrplatform.h` notice; Apache-2.0 is compatible with GPLv3 |
| `mtwist.c` (`extern/mtwist`, from Space Nerds In Space `e8ad8165`, Stephen M. Cameron) | Seeded random numbers, for seed compatibility with the labs | GPL-2.0-or-later | Keep its copyright header; usable under GPLv3 by "or later" |
| stb_image_write (`extern/stb`, commit `1ee679ca`, v1.16) | PNG output | MIT or public domain | None beyond keeping the notice |
| tinyexr (`extern/tinyexr`, `v3.2.0`: `tinyexr.h`, `exr_reader.hh`, `streamreader.hh`) | OpenEXR output | BSD-3-Clause, with OpenEXR code under ILM's BSD-style licence | Keep the notices (`LICENSE`, the header of `tinyexr.h`) |
| miniz (`extern/tinyexr`, as bundled with tinyexr `v3.2.0`) | ZIP compression for OpenEXR | MIT | Keep the notice (`LICENSE.miniz`) |
| toml++ (`extern/tomlplusplus`, `v3.4.0`, single header) | Project files | MIT | Keep the notice |

The reference-sky measurements the palette space is fitted to are numbers, not
components; their provenance is recorded in `docs/references/SOURCES.md`.

KTX2 is written by StarCanopy's own code (`src/core/ktx2.cpp`), not by
KTX-Software's libktx as first planned: an uncompressed half-float cubemap is a
few hundred lines of a documented format, where libktx is a large library with
its own build. Its output is checked with KTX-Software's `ktx validate`.
